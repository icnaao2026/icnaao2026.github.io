# ICNAAO 2026: ข้อเสนอการแบ่งบทบาท หน้าที่ และความรับผิดชอบของแต่ละฝ่าย

**วันและสถานที่จัดประชุม:** 14–16 ธันวาคม 2569 (ค.ศ. 2026) ณ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี กรุงเทพมหานคร  
**สถานะ:** ข้อเสนอเพื่อให้คณะกรรมการพิจารณาและตกลงร่วมกัน  
**ฉบับภาษาอังกฤษ:** [README.en.md](README.en.md)

ข้อเสนอนี้กำหนดหน้าที่ก่อนและระหว่างการประชุม หัวหน้าแต่ละฝ่ายรับผิดชอบการวางแผน มอบหมายงาน ติดตามความพร้อม และแก้ไขปัญหาภายในฝ่าย รวมทั้งควรแต่งตั้งผู้แทนที่สามารถตัดสินใจเรื่องงานประจำได้เมื่อหัวหน้าฝ่ายไม่อยู่

## 1. ฝ่ายวิชาการ

**หัวหน้าฝ่าย: Pawaton Kaemawichanurat**

**บทบาท:** ดูแลคุณภาพทางวิชาการ จัดทำกำหนดการวิชาการที่เหมาะสม  และกำกับให้การนำเสนอเป็นไปตามแผน

### ก่อนวันประชุม

[x] < PC > จัดการการรับบทคัดย่อ ตรวจสอบความครบถ้วนและความสอดคล้องกับหัวข้อการประชุม ประสานผู้ประเมิน และจัดเตรียมผลการพิจารณาตามเกณฑ์ที่ตกลงกับประธานจัดการประชุม
[x] < PC > จัดเตรียมหนังสือตอบรับและคำแนะนำสำหรับผู้นำเสนอ รวมทั้งขอให้แก้ไขบทคัดย่อเมื่อจำเป็น
[ ] ประสาน Keynote and Invited speakers โดยรวบรวมการยืนยันเข้าร่วม ประวัติย่อ
[ ] จัดกลุ่มการนำเสนอตามหัวข้อ กำหนดเวลาบรรยายและอภิปราย ป้องกันตารางเวลาซ้อนกันของผู้นำเสนอ และแต่งตั้งประธานแต่ละช่วงการนำเสนอ โดยจัดประธานและทีมสนับสนุนให้ครบทั้งสองห้องคู่ขนาน
[ ] ยืนยันประธานแต่ละช่วงการนำเสนอ (Chairperson) ให้ครบทุกช่วง จัดตารางปฏิบัติงานและผู้แทนสำรอง พร้อมเตรียมกำหนดการ รายชื่อและประวัติวิทยากร แนวทางแนะนำผู้บรรยาย การดำเนินช่วงถาม–ตอบ และการควบคุมเวลา
[ ] จัดผู้ช่วยประจำห้องบรรยายและผู้จับเวลาให้ครบทุกห้องและทุกช่วง โดยระบุหน้าที่และช่วงปฏิบัติงานให้ชัดเจน ฝ่ายวิชาการรับผิดชอบการจัดคนและชี้แจงงาน ส่วนฝ่ายต้อนรับและสถานที่สนับสนุนการจัดหาอาสาสมัครและความช่วยเหลือด้านเทคนิค
[ ] จัดทำและจัดเตรียมป้ายบอกเวลาประจำแต่ละห้อง เช่น “เหลือ 5 นาที” “เหลือ 1 นาที” และ “หมดเวลา” พร้อมอุปกรณ์จับเวลาและอุปกรณ์สำรอง โดยกำหนดจังหวะเตือนให้เหมาะกับระยะเวลาบรรยายแต่ละประเภท และชี้แจงสัญญาณให้ประธาน ผู้นำเสนอ และผู้จับเวลาเข้าใจตรงกัน
[ ] จัดทำรายการตรวจสอบสำหรับผู้ช่วยประจำห้อง ครอบคลุมการตรวจสอบการมาถึงของวิทยากร ความพร้อมของไฟล์นำเสนอ การช่วยส่งไมโครโฟนช่วงถาม–ตอบ การบันทึกการนำเสนอ และวิธีติดต่อเมื่อเกิดปัญหาทางเทคนิค
[ ] รวบรวมและตรวจทานหนังสือรวมบทคัดย่อและกำหนดการฉบับละเอียด โดยตรวจสอบชื่อ สังกัด ชื่อเรื่อง และช่วงการนำเสนอ
[ ] ตรวจสอบรายชื่อผู้นำเสนอร่วมกับฝ่ายลงทะเบียนก่อนสรุปกำหนดการ และส่งกรณีที่ยังมีปัญหาด้านการลงทะเบียนให้ผู้มีอำนาจพิจารณาตามแนวทางที่ตกลงไว้
[ ] กำหนดวิธีรับมือกรณีผู้นำเสนอไม่มา มาสาย ใช้เวลาเกิน หรือเกิดปัญหาทางเทคนิค
[ ] ยืนยันรายละเอียดวารสารฉบับพิเศษและสื่อสารขั้นตอนการส่งบทความให้ถูกต้อง การตอบรับให้นำเสนอในการประชุมไม่ได้หมายถึงการตอบรับตีพิมพ์ในวารสาร ซึ่งยังต้องผ่านกระบวนการพิจารณาของวารสาร

### ในวันประชุม

[ ] กำกับการดำเนินรายการวิชาการ และชี้แจงประธานแต่ละช่วงเกี่ยวกับเวลา การแนะนำวิทยากร การอภิปราย และการรายงานการเข้าร่วม
[ ] ตรวจสอบว่าประธาน ผู้ช่วยประจำห้อง ผู้จับเวลา ป้ายบอกเวลา และอุปกรณ์จับเวลาพร้อมก่อนเริ่มแต่ละช่วง และจัดผู้แทนทดแทนเมื่อจำเป็น
[ ] จับเวลาการบรรยายและช่วงถาม–ตอบ แสดงป้ายเตือนตามที่ตกลง และแจ้งประธานเมื่อหมดเวลาเพื่อควบคุมการดำเนินรายการให้ตรงกำหนด
[ ] ให้ผู้ช่วยประจำห้องตรวจสอบความพร้อมของวิทยากรลำดับถัดไป ประสานเจ้าหน้าที่เทคนิคเรื่องไฟล์นำเสนอ ช่วยส่งไมโครโฟนช่วงถาม–ตอบ และบันทึกการนำเสนอจริงรวมถึงปัญหาที่เกิดขึ้น
[ ] ตรวจสอบความพร้อมและการมาถึงของวิทยากรก่อนเริ่มแต่ละช่วง และจัดการการเปลี่ยนแปลงกำหนดการวิชาการ
[ ] ประสานฝ่ายต้อนรับและสถานที่เมื่อมีปัญหาอุปกรณ์หรือความพร้อมของห้อง
[ ] ส่งข้อมูลการแก้ไขกำหนดการที่ยืนยันแล้วให้ฝ่ายประชาสัมพันธ์แจ้งผู้เข้าร่วมทันที
[ ] บันทึกการนำเสนอจริง การถอนตัว และการไม่มานำเสนอ พร้อมตรวจสอบสิทธิ์ในการรับเกียรติบัตรผู้นำเสนอ

**ผลงานหลักที่ต้องจัดเตรียม:** รายการบทคัดย่อที่ผ่านการพิจารณา รายชื่อวิทยากรที่ยืนยันแล้ว กำหนดการวิชาการฉบับละเอียด หนังสือรวมบทคัดย่อ ตารางประธานและผู้ช่วยประจำห้องพร้อมผู้แทนสำรอง แนวทางสำหรับประธานแต่ละช่วง รายการตรวจสอบสำหรับผู้ช่วยประจำห้อง ป้ายบอกเวลาและอุปกรณ์จับเวลาครบทุกห้อง และบันทึกการนำเสนอ

## 2. ฝ่ายลงทะเบียนและการเงิน

**หัวหน้าฝ่าย: Sukuman Sarikavanij**

**บทบาท:** ดูแลข้อมูลผู้เข้าร่วมและการเงินให้ถูกต้อง พร้อมให้บริการลงทะเบียนและรับชำระเงินอย่างเป็นระบบ

### ก่อนวันประชุม

[ ] จัดทำทะเบียนผู้เข้าร่วม โดยระบุประเภทผู้เข้าร่วม สังกัด ข้อมูลติดต่อ ผู้ติดตาม และข้อมูลที่จำเป็นต่อการเข้าร่วม
[ ] จัดเตรียมและทดสอบช่องทางชำระเงิน แจ้งวิธีชำระ ตรวจสอบยอดรับ และจัดทำใบแจ้งหนี้และใบเสร็จรับเงินตามกระบวนการของมหาวิทยาลัย
[ ] ใช้อัตราค่าลงทะเบียนตามที่อนุมัติ ตรวจสอบสถานภาพนักศึกษาและสิทธิ์อัตราลงทะเบียนล่วงหน้า และเสนอกรณีส่วนลดพิเศษ การคืนเงิน หรือการยกเว้นค่าลงทะเบียนให้ประธานจัดการประชุมพิจารณา
[ ] รวบรวมประมาณการงบประมาณจากทุกฝ่าย ติดตามรายรับและภาระค่าใช้จ่าย ระบุส่วนที่งบประมาณยังไม่เพียงพอ และประสานขั้นตอนจัดซื้อและเบิกจ่ายที่ได้รับอนุมัติ
[ ] < ประสาน PC > จัดเตรียมข้อมูลป้ายชื่อ รายชื่อสำหรับเช็กอิน รายการใบเสร็จ และชื่อสำหรับเกียรติบัตร พร้อมประสานจำนวนและการจัดชุดเอกสารกับฝ่ายต้อนรับและสถานที่
[ ] ตรวจสอบข้อมูลและสถานะการลงทะเบียนสำหรับหนังสือเชิญ จัดเตรียมหนังสือให้ผู้มีอำนาจลงนาม และประสานรายละเอียดทางวิชาการกับฝ่ายวิชาการ
[ ] ส่งยอดผู้รับอาหาร ผู้ร่วมงานเลี้ยง และผู้ติดตาม รวมถึงข้อจำกัดด้านอาหารหรือความต้องการด้านการเข้าถึงสถานที่ให้ฝ่ายต้อนรับและสถานที่ โดยส่งเฉพาะข้อมูลที่จำเป็น

### ในวันประชุม

[ ] ดูแลจุดลงทะเบียน การเช็กอิน การแก้ไขป้ายชื่อ การแจกชุดเอกสาร และการลงทะเบียนเพิ่มเติมตามกติกาที่ตกลงไว้
[ ] แก้ไขปัญหาการชำระเงินโดยคำนึงถึงความเป็นส่วนตัว และออกใบเสร็จตามกระบวนการที่กำหนด
[ ] ปรับปรุงข้อมูลการเข้าร่วมและการชำระเงิน และแจ้งฝ่ายวิชาการเมื่อพบปัญหาสถานะลงทะเบียนของผู้นำเสนอ
[ ] ควบคุมการรับชำระหน้างานและเงินสดย่อย หากมี โดยมีหลักฐานรายการและตรวจสอบยอดทุกวัน
[ ] < ประสาน PC >ตรวจสอบชื่อและสิทธิ์รับเกียรติบัตร และประสานการแจกกับฝ่ายที่เกี่ยวข้อง
[ ] บันทึกค่าใช้จ่ายเพิ่มเติมที่ได้รับอนุมัติและเก็บเอกสารประกอบให้ครบถ้วน

**ผลงานหลักที่ต้องจัดเตรียม:** ทะเบียนผู้เข้าร่วม รายงานตรวจสอบยอดชำระ ตารางติดตามงบประมาณ ใบเสร็จ เอกสารลงทะเบียน และข้อมูลเกียรติบัตรที่ตรวจสอบแล้ว

## 3. ฝ่ายต้อนรับและสถานที่

**หัวหน้าฝ่าย: Songpon Sriwongsa**

**บทบาท:** ต้อนรับผู้เข้าร่วมและดูแลสถานที่ อุปกรณ์ อาหาร และการอำนวยความสะดวกให้รองรับกำหนดการประชุม

### ก่อนวันประชุม

[ ] ยืนยันห้องบรรยายรวม ห้องคู่ขนาน พื้นที่ลงทะเบียนและรับประทานอาหาร รวมถึงความจุ การเข้าถึง และเวลาเปิดใช้งาน
[ ] ทดสอบเครื่องฉาย ไมโครโฟน คอมพิวเตอร์นำเสนอ การเชื่อมต่อ อินเทอร์เน็ต และอุปกรณ์สำรอง พร้อมกำหนดผู้ประสานงานด้านเทคนิคประจำแต่ละห้อง
[ ] จัดอาหารว่าง อาหารกลางวัน น้ำดื่ม และงานเลี้ยงตามจำนวนผู้เข้าร่วมที่ยืนยันแล้วและงบประมาณที่อนุมัติ
[ ] ประสานการต้อนรับวิทยากร การติดต่อที่พัก และการเดินทาง เฉพาะส่วนที่คณะกรรมการตกลงจัดให้
[ ] ประสานโรงแรมและที่พักใกล้ มจธ. วิทยาเขตบางมด เพื่อสอบถามจำนวนห้องว่างในช่วงประชุม อัตราค่าห้องพักหรือราคาพิเศษสำหรับผู้เข้าร่วม เงื่อนไขการจองและยกเลิก รวมถึงการเดินทางมายังสถานที่ประชุม และส่งข้อมูลที่ยืนยันแล้วให้ฝ่ายประชาสัมพันธ์แจ้งผู้เข้าร่วม หากมีการสำรองห้องหรือค่าใช้จ่ายในนามผู้จัด ต้องได้รับอนุมัติก่อน
[ ] จัดทำผังห้อง ตำแหน่งป้ายบอกทาง อุปกรณ์จุดลงทะเบียน แผนจัดชุดเอกสาร และตารางติดตั้ง
[ ] จัดหาและชี้แจงงานอาสาสมัครด้านต้อนรับ ประจำห้อง นำทาง และบริการอาหาร โดยกำหนดช่วงปฏิบัติงานและผู้บังคับบัญชาให้ชัดเจน
[ ] เตรียมผู้ติดต่อและขั้นตอนรับมืออุปกรณ์ขัดข้อง การเดินทางล่าช้า ของสูญหาย การขอความช่วยเหลือทางการแพทย์ และการอพยพ โดยประสานหน่วยงานของมหาวิทยาลัย
[ ] เตรียมที่นั่ง ไมโครโฟน เวที และการซักซ้อมพิธีเปิดและพิธีปิด

## 5. การประสานงานและอำนาจตัดสินใจ

| เรื่อง | ฝ่ายรับผิดชอบหลัก | การประสานงานที่จำเป็น |

## 6. ประเด็นที่ต้องยืนยัน

ข้อมูลในโครงการขณะจัดทำข้อเสนอยังระบุว่าช่องทางชำระเงินอยู่ระหว่างเตรียมการ ฝ่ายลงทะเบียนและการเงินควรจัดทำและตรวจสอบกระบวนการให้เรียบร้อย แล้วส่งคำแนะนำที่ยืนยันแล้วให้ฝ่ายประชาสัมพันธ์เผยแพร่

สิทธิ์การลงทะเบียนระบุอาหารกลางวันครบสามวันและงานเลี้ยง แต่กำหนดการเบื้องต้นสิ้นสุดเวลา 12:30 น. ในวันสุดท้าย และยังไม่ระบุช่วงงานเลี้ยง ฝ่ายลงทะเบียนและฝ่ายต้อนรับควรยืนยันรายละเอียดร่วมกัน ฝ่ายวิชาการจัดเวลาให้สอดคล้อง และฝ่ายประชาสัมพันธ์ปรับปรุงข้อมูลที่เผยแพร่
