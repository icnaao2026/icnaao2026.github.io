    Beyond Norms: Modular Topology and Applications to Partial Differential Equations

    Mohamed Amine Khamsi

    Read abstract

    Modular spaces provide a natural setting for nonlinear problems with variable growth. Although these spaces carry a Luxemburg norm, modular convergence can be strictly weaker than norm convergence when the \(\Delta_2\) condition fails. This distinction becomes especially significant in variable exponent spaces with unbounded exponents.

    In this talk, we study the sequential topology associated with modular convergence and its compatibility with the underlying vector space structure. We characterize the \(\Delta_2\) condition through the equivalence of modular and norm topologies. Examples in variable exponent sequence and function spaces illustrate the contrasting behavior beyond this condition: modular balls can have empty interior, and the modular topology can remain Hausdorff and separable while failing to be first-countable.

    We then discuss applications to the Dirichlet problem for the \(p(x)\)-Laplace equation with unbounded exponents. Modular uniform convexity and modular closure provide a framework for establishing unique variational minimizers and their corresponding Euler identities. Particular attention is given to the admissible boundary class and the choice of test functions.

    The talk draws on joint work with Jan Lang and Osvaldo Méndez, including earlier work with Aleš Nekvinda.

    Fixed-Point Delayed Subgradient Methods for Nonsmooth Convex Optimization Problems

    Nimit Nimana

    Read abstract

    In this talk, we focus on solving of the minimization problem of a convex function over a fixed-point constraint of the following form: \[\begin{array}{ll} \textrm{minimize }\quad f(\mathbf{x})\\ \textrm{subject to}\quad \mathbf{x}\in \displaystyle\mathrm{Fix}(T), \end{array} \] where the objective function \(f:\mathbb{R}^d \to \mathbb{R}\) is convex and the constraint operator \(T:\mathbb{R}^d \to \mathbb{R}^d\) is firmly nonexpansive with \(\displaystyle\mathrm{Fix}(T):=\{ \mathbf{x}\in\mathbb{R}^d:T( \mathbf{x})= \mathbf{x}\} \neq \emptyset\). To find an optimal solution of the problem, we present an iterative method based on the hybrid steepest descent method and the idea of a delayed subgradient scheme in which allows the use of staled subgradients from the earlier iteration when updating the next iteration. We start the convergence part by deriving an upper bound for the difference of the best-achieved function values and the optimal value. After that, to ensure the convergence in iterations, we prove that there exists a subsequence of the generated sequence by the proposed method which converges to an optimal solution. Moreover, we subsequently show that the whole generated sequence converges to an optimal solution when the strict convexity of the objective function is imposed. Further, we extend the presented results to the inexact version and the centralized network system consisting of a finite number of workers and a central server. Finally, we apply the proposed method to image inpainting problems. The numerical results describe the effect of delay in many cases of objective functions.

    Keywords: Convex Optimization; Delay; Firmly Nonexpansive; Fixed Point; Nonsmooth Optimization; Subgradient Method.

    A Two-Step Inertial Tseng Splitting Algorithm with Dynamic Reference Point Projections for Monotone Inclusions and Biomedical Diagnostics

    Duangkamon Kumtaeng

    Read abstract

    In this paper, we propose an accelerated iterative method, termed the two-step inertial Tseng splitting algorithm with dynamic reference point projection (2I-Tseng-DRPP), for solving monotone inclusion problems in real Hilbert spaces. The algorithm combines two-step inertial extrapolation [2] to improve convergence rates, Tseng's forward–backward–forward operator splitting [1] to relax cocoercivity requirements on the operator to Lipschitz continuity, and a dynamic reference point projection onto a single dynamically updated half-space containing the solution set [3]. Under standard control assumptions, we establish a strong convergence theorem for the proposed algorithm without requiring the calculation of intersections of multiple half-spaces. Furthermore, to demonstrate the practical efficiency of the theoretical scheme, we apply the 2I-Tseng-DRPP method to extreme learning machine (ELM) models equipped with LASSO regularization for biomedical data classification tasks. Numerical experiments on four benchmark biomedical datasets (Parkinson's disease, Diabetes, Heart disease, and Wisconsin Diagnostic Breast Cancer (WDBC)) using 10-fold cross-validation demonstrate that the proposed algorithm achieves higher classification accuracy and lower objective values compared to BiG-SAM, iBiG-SAM, and the standard two-step inertial forward–backward method.

    Keywords: Monotone inclusion; Two-step inertial algorithm; Tseng splitting method; Dynamic reference point projection; Biomedical data classification.

    A Block Proximal-Gradient Method with Adaptive Step Sizes for Separable Composite Convex Minimization

    Sani Salisu

    Read abstract

    We consider the separable composite convex problem of the form \[\begin{align*} \min_{x\in\mathbb{R}^m}\ F(x):=f(x)+\sum_{i=1}^{p}g_i(x^i), \end{align*}\] where \(f\) is convex with a Lipschitz continuous gradient and each \(g_i\) is a proper, convex and lower semicontinuous function acting on the block \(x^i\) of \(x\). Such problems arise in sparse regression and data classification, where a full gradient evaluation is the dominant cost. In this talk, we present a block proximal-gradient method in which the blocks are updated in any order within each sweep, using the latest available values, and each block carries its own step size. This step size is learned from the change of the partial gradient of the block between two consecutive sweeps, following the curvature-estimate rules of [3, 2], so that neither a line search nor the Lipschitz constants are required. For convex \(f\), we show that the objective values decrease monotonically and, when the initial level set is bounded, converge at the rate \(O(1/n)\), and the iterates converge to a minimizer. For strongly convex \(f\), both the objective values and the iterates converge linearly for every block order, and, with a single block, the iterates converge without a bounded level set. Experiments on Lasso-regularized extreme learning machines and elastic-net support vector machines for handwritten digit classification show that the method often reaches a given accuracy in far fewer sweeps than the cyclic block method of [1], FISTA and the full-gradient adaptive methods of [3, 2].

    Keywords: Proximal-gradient method; block coordinate method; adaptive step size; composite convex optimization; data classification.

    Mathematics Subject Classification: Primary 90C25, 65K05; Secondary 90C06, 49M37.

    On the numerical solution of the third and fourth Painlevé equations arising in two-dimensional quantum gravity via Haar wavelets based algorithms

    Abdul Ahad

    Read abstract

    This study presents an efficient numerical scheme based on the Haar wavelet collocation method (HWCM) for solving initial and boundary value problems of the nonlinear third Painlevé (\(P_{\text{III}}\)) equation. To handle the rational nonlinearity and the singular behavior at the origin, the differential equation is cleared of fractions and linearized via Newton–Kantorovich quasilinearization. The highest-order derivative is expanded in terms of Haar wavelets, and the expressions for the lower-order derivatives and dependent variable are derived by integrating the Haar series alongside the prescribed initial or boundary conditions. Evaluating the resulting equations at the collocation points yields a system of linear algebraic equations at each iteration step. Theoretical error bounds and convergence in the \(L^2\)-norm are established. Numerical experiments are carried out on various benchmark examples at different wavelet resolution levels \(J\). The computed \(L_\infty\) and \(L_2\) error norms confirm that the proposed Haar wavelet approach yields highly accurate results even for a small number of grid points and outperforms standard finite-difference and Runge–Kutta schemes.

    Keywords: Haar wavelet; Third and fourth Painlevé equations; Operational matrix of integration; Quasilinearization technique; Rational nonlinearities; Convergence analysis.

    Investigating the Optimal Balance Between Natural Killer Cells and Oncolytic Viruses Using Discrete Fractional-Order Modeling and Artificial Neural Networks

    Zeeshan Ali

    Read abstract

    Oncolytic virotherapy is a promising cancer treatment that uses viruses to selectively infect and destroy tumor cells. However, the role of natural killer (NK) cells remains complex, as their activation may enhance tumor destruction while also restricting viral replication. In this study, we investigate the optimal balance between NK cells and oncolytic viruses using a discrete fractional-order mathematical model that describes the interactions among uninfected cancer cells, infected cancer cells, free viruses, and NK cells. The model incorporates memory effects through the Caputo fractional difference operator. We establish the existence and uniqueness of solutions using fixed-point theorems and analyze the equilibrium points and their stability. The basic reproduction number (\(\mathcal{R}_0\)) is derived using the next-generation matrix method, followed by sensitivity analysis to identify influential parameters. Numerical simulations investigate the effects of viral burst size, NK-cell activation, and fractional order on the system dynamics, highlighting the importance of balancing viral replication and immune response. Furthermore, an artificial neural network trained on numerically generated data is employed to approximate the discrete fractional-order dynamics, demonstrating close agreement with the numerical solutions. The findings provide mathematical and computational insights into the interplay between NK cells and oncolytic viruses and their implications for effective virotherapy [1].

    Keywords: Oncolytic virotherapy; Natural killer cells; Discrete fractional-order model; Artificial neural networks.

    Response Surface Optimization of Thermal and Mass Transport in Porous Media for Biomedical Microfluidic Systems using Numerical Simulation and Artificial Intelligence

    Talal Taha

    Read abstract

    Sensitivity analysis is essential for identifying dominant physical parameters and evaluating their influence on thermal transport, enabling effective optimization of complex engineering systems. Electroosmotic micropumps have important applications in biomedical microfluidic devices, where controlled transport and efficient thermal management are required for reliable performance. This study investigates electroosmotic peristaltic transport and heat transfer through a non-Darcy porous medium under the combined effects of magnetic fields, Joule heating, nanoparticles concentration, and viscous dissipation. A hybrid framework integrating numerical simulation and Response Surface Methodology (RSM) is employed to analyze the governing nonlinear equations, examine parameter interactions, and optimize thermal performance. Sensitivity analysis is conducted using the rate of change of response variables with respect to governing parameters to identify dominant factors. Statistical significance is evaluated at the 5 % level, with p < 0.05 considered significant. The results indicate that increasing the Hartmann number reduces axial velocity in the central microchannel region, whereas Joule heating increases temperature. Furthermore, the Brinkman number and Joule heating parameter strongly influence the Nusselt number, highlighting their importance in thermal regulation. The proposed hybrid approach combines numerical predictions, statistical optimization, and sensitivity assessment to identify influential parameters and support improved thermal performance. These findings provide theoretical guidance for optimizing electroosmotic micropumps and developing thermally efficient biomedical microfluidic systems.

    Keywords: Electroosmotic peristaltic flow; Biomedical microfluidic devices; Magnetohydrodynamics (MHD); Numerical simulation; Response Surface Methodology (RSM); Optimization.

    News-aided Epidemic Management: Controlling Peak Infection Levels

    Madhu Dhiman

    Read abstract

    We study the control of an epidemic whose dynamics are influenced by news propagation on online social networks (OSNs). In our earlier work [1], we developed an integrative model combining news propagation and epidemic dynamics and studied its equilibrium behavior; in particular, the paper shows that interactions between the two processes can generate periodic fluctuations in infection levels even without mutation. Building on this framework, the present work focuses on controlling the spread of infection through the dissemination of authentic information on OSNs. We first consider a control problem in which the controller aims to minimize the cumulative number of infections while accounting for the cost of information dissemination. We establish theoretical results characterizing the structure of an optimal control policy and show that, under suitable conditions, it is optimal to use the minimum dissemination effort during both the initial and final parts of the planning horizon.

    We then extend the formulation to account for peak infections, in addition to cumulative infections and the cost of information dissemination, since the peak infection levels reflect huge burden on the healthcare system. This leads to a non-standard optimal control problem with an objective combining integral and \(L^\infty\) costs. Building on the solution approach developed in our recent work [2], we establish the existence of an optimal relaxed control and, using the smooth approximation technique developed therein, the existence of an \(\epsilon\)-optimal pure control. We numerically solve the resulting smooth approximate problem to investigate optimal information dissemination policies under different priorities. In particular, we compare a policy that prioritizes reducing peak infections with one that prioritizes minimizing cumulative infections, while keeping their cumulative information dissemination costs nearly equal. The results reveal a trade-off: the peak-prioritizing policy substantially reduces peak infections, whereas the other achieves a lower overall infection burden. However, interestingly, the number of periodic epidemic fluctuations remains the same under both policies. Moreover, the peak-prioritizing policy follows an upfront dissemination strategy, preventing the initial peak from escalating and keeping subsequent peaks below it. On the other hand, the policy optimal for the cumulative infection objective is once again vigilant: it is again optimal to use minimal dissemination effort at the beginning and end of the horizon.

    Keywords: Epidemic dynamics, Online social networks, Information dissemination, Misinformation, Peak-sensitive optimal control, \(L^\infty\)-optimal control.

    Optimal Control and Cost-Effectiveness of Smoking Dynamics with Saturated Treatment

    Tariq Hassan

    Read abstract

    Smoking remains a major public health concern, highlighting the need for effective and economically efficient intervention strategies. This study develops a nonlinear mathematical model of smoking dynamics that incorporates smoking initiation, cessation treatment, treatment failure, relapse, and permanent quitting. The population is divided into five compartments: susceptible individuals, active smokers, individuals undergoing cessation treatment, temporary quitters, and permanent quitters. A nonlinear saturated treatment function is introduced to account for limitations in treatment enrollment as the smoking population increases. The mathematical analysis investigates the fundamental properties of the model, while normalized sensitivity indices are employed to identify influential parameters governing smoking dynamics. Three time-dependent interventions, namely smoking prevention, enhanced treatment enrollment, and relapse prevention, are incorporated into an optimal control framework. Pontryagin's maximum principle is applied to derive the necessary optimality conditions, and the resulting control problem is investigated numerically using the fourth-order Runge–Kutta method combined with constrained optimization. Seven intervention strategies are evaluated individually and in combination, and their economic performance is assessed using average and incremental cost-effectiveness ratios (ACER and ICER). Numerical results indicate that smoking prevention is the most effective individual intervention, reducing cumulative smoking burden by approximately \(75.79\%\), while enhanced treatment enrollment achieves a reduction of \(49.15\%\). The combined implementation of all three controls produces the greatest reduction of approximately \(81.51\%\), whereas prevention combined with treatment achieves a comparable reduction of \(81.48\%\) at a slightly lower intervention cost. Furthermore, treatment saturation analysis reveals that increasing treatment limitations raises the absolute smoking burden, emphasizing the importance of adequate treatment capacity. The findings demonstrate the potential value of integrating preventive and treatment-based interventions and provide a quantitative framework for comparing smoking control strategies under resource constraints.

    Keywords: Smoking dynamics; nonlinear mathematical modeling; saturated treatment; sensitivity analysis; optimal control; numerical simulation; cost-effectiveness analysis.

    Unified Perturbation Functions for Resolvent Operators in Geodesic Spaces

    Yasunori Kimura

    Read abstract

    Resolvent operators are important tools in convex analysis and optimization. In particular, they are useful for convex minimization problems. In Hilbert spaces, the resolvent operator of a proper lower semicontinuous convex function is defined by using a quadratic perturbation term. This definition can also be extended to complete \(\textup{CAT}(0)\) spaces.

    In geodesic spaces with positive or negative curvature, different perturbation functions have been used to define resolvent operators. For example, resolvent operators on admissible complete \(\textup{CAT}(1)\) spaces are defined by using trigonometric functions, while those on complete \(\textup{CAT}(-1)\) spaces are defined by using hyperbolic functions [1, 3]. These operators are well-defined as single-valued mappings and satisfy certain nonspreading properties. Their fixed point sets coincide with the sets of minimizers of the corresponding convex functions.

    Recently, Kajimura, Kimura, and Kohsaka [2] introduced other types of resolvent operators by combining different perturbation functions in \(\textup{CAT}(1)\) and \(\textup{CAT}(-1)\) spaces. These results show the importance of choosing suitable perturbation functions.

    In this talk, we consider a unified definition of resolvent operators on complete \(\textup{CAT}(\kappa)\) spaces for any real number \(\kappa\). We introduce perturbation functions which can be used for positive, zero, and negative curvature. Using these functions, we define resolvent operators associated with proper lower semicontinuous convex functions. We show that these operators are well-defined as single-valued mappings and that their fixed point sets coincide with the sets of minimizers of the corresponding functions. We also prove that these operators satisfy a common nonspreading inequality, called \(\kappa\)-nonspreadingness.

    Keywords:

    Resolvent operator, perturbation function, geodesic space.

    References
    1. T. Kajimura and Y. Kimura, Resolvents of convex functions in complete geodesic spaces with negative curvature, J. Fixed Point Theory Appl. 21 (2019), 32.
    2. T. Kajimura, Y. Kimura, and F. Kohsaka, Resolvents for convex functions on geodesic spaces and their nonspreadingness, Axioms 14 (2025), 295.
    3. Y. Kimura and F. Kohsaka, Spherical nonspreadingness of resolvents of convex functions in geodesic spaces, J. Fixed Point Theory Appl. 18 (2016), 93–115.

    A Unified Resolvent–Yosida–Cayley Approach to Systems of Nonlinear Variational Inclusions in q-Uniformly Smooth Banach Spaces

    Mohd. Sharique

    Read abstract

    This paper develops a unified operator framework for a system of generalized nonlinear variational inclusions governed by \(A\)-maximal \(m\)-relaxed \(\eta\)-accretive mappings in \(q\)-uniformly smooth Banach spaces. The problem is to find a common solution of the inclusion system and a fixed point of a nearly uniformly Lipschitzian mapping \(Q=(S_1,S_2,\ldots,S_p)\).

    Motivated by resolvent techniques for accretive variational inclusions and developments involving Yosida and Cayley operators, we establish a fixed-point representation that incorporates all three operator families. For each component of the system, the resolvent, Yosida, and Cayley operators are combined through \(\mathcal V_i\), together with a coupled perturbation \(\mathcal T_i\) and a regularization term involving \(\mathcal M_i\).

    This representation leads to a \(p\)-step iterative scheme with mixed errors in which the three operator families enter explicitly. Under appropriate accretivity and Lipschitz assumptions, together with restrictions on the iteration parameters and error terms, we prove convergence of the generated sequence to a common solution of the variational inclusion system and the fixed-point problem. The contribution is an extension of the resolvent-based framework that integrates Yosida and Cayley operators within a single iterative formulation for coupled nonlinear inclusions in Banach spaces.

    Keywords: Algorithms; Accretive; Strong Accretive; Relaxed Accretive; Inclusion; Iterative methods; Numerical Simulation; strong convergence.

    Read abstract

    When a service system offers a lounge next to its queue, some customers always join the queue, while others wait in the lounge when the queue is long and join it only once it has emptied. The others are waiting-time conscious (WT) and always join the queue. Lounge customers move to the queue only when it becomes empty. We show that a CS customer goes to the lounge exactly when the queue is longer than a threshold \(A\), which depends on the waiting costs but not on \(\alpha\), and that the system is stable when the traffic intensity is strictly lesser than one.

We therefore build the Q-Alone Tracking (QAT) process, which only tracks the change in queue while still retaining the influence of the lounge evolution. We prove that QAT process produces the same queue length as the original system at every moment, and use it to obtain the stationary queue-length distribution in closed form. This also gives the distribution of lounge occupancy because the total number of customers behaves exactly like an M/M/1 queue. We also show that the queue becomes longer when the lounge is less comfortable or when fewer customers are CS type.

    Finally, we study lounge design. A very comfortable lounge diverts many customers, but its benefit per diverted customer falls as the CS fraction grows, so maximizing diversion is not the right goal. To keep the queue within a target range, we prove for \(\alpha=1\) that a moderately comfortable lounge, not the most comfortable one, is optimal; numerically, this holds for all \(\alpha\).     Read abstract

The model integrates complementary information from multiple views to capture different characteristics of the optic nerve head and retinal vasculature. However, effectively combining the probability predictions from these views requires an appropriate fusion strategy that satisfies the probability simplex constraint \(\Delta_k = {w \in \mathbb{R}^k : w_i \ge 0, , \mathbf{1}^T w = 1}\) while ensuring stable and auditable optimization. Furthermore, a second-order curvature bound certifies the insensitivity of the objective to feasible weight perturbations. Integrated via adaptive Runge–Kutta methods, the gradient flow matches direct sequential quadratic programming solvers to within \(10^{-15}\) in objective value. On an independent locked test set of 1,264 images, three-view neurodynamic fusion achieves an AUC of 96.9% with 79.0% sensitivity and 94.9% specificity. These results demonstrate the effectiveness of the proposed framework and support its theoretical stability properties.

    From Classical Riemann Integration to the Lebesgue Property of Banach Spaces

    Lakshmi Kanta Dey

    Read abstract

    The theory of Riemann integration plays a fundamental role in classical analysis and provides one of the earliest notions of integration for real-valued functions defined on a closed interval. In this talk, we briefly review some basic aspects of Riemann integrability and discuss the celebrated result that every Riemann integrable real-valued function is bounded and continuous almost everywhere.

    We then turn to the setting of Banach space-valued functions, where several phenomena arise that have no counterpart in the scalar case. In particular, a Riemann integrable function taking values in a Banach space need not be continuous almost everywhere. This naturally leads to the notion of the Lebesgue property: a Banach space is said to possess the Lebesgue property if every Riemann integrable function with values in that space is continuous almost everywhere.

    The characterization of Banach spaces enjoying the Lebesgue property has attracted considerable attention and reveals deep connections between integration theory, measure theory, and the geometric structure of Banach spaces. The talk will present some classical results, recent developments, and selected open problems in this area.

    On the Construction of Graphs with Given Integer Eigenvalues

    Paparb Hatnumsap

    Read abstract

    The adjacency matrix of a graph is used to examine and solve problems on a graph. Moreover, the spectrum of the adjacency matrix of a graph is a powerful tool for analyzing the structure of chemical atoms and complex networks [1, 2]. The eigenvalues of a graph can be used to optimize specific problems and help identify the most suitable graph structure for a given application. Modern optimization algorithms are applied to determine the maximum value among all strategies within a graph. Therefore, we propose extending the scope of these optimization methods to determine the maximum value of all strategies across graphs. Hence, each application requires a distinct eigenvalue of the adjacency matrix to determine the most effective strategy. One important topic of study that arises is how we can systematically construct such graphs to realize particular spectral properties. In this talk, we introduce technuques for constructing graphs whose spectra contain a specified set of integer eigenvalues. Our study investigates the properties of \(\lambda\)-nut graphs, [3], to systematically identify graphs with \(\lambda\) in their spectrum. Furthermore, we demonstrate how combining graphs with different eigenvalues enables the construction of new graphs that collectively exhibit all desired spectral properties. We also introduce techniques to generate graphs whose spectra include any given set of integer values, providing new tools for network design and spectral graph theory.

    Keywords: Adjacency matrix, Graph construction, Spectral graph.
